# Pickup (read this first on a cold start)

1. `git pull`.
2. Read `CHARTER.md` and `RISK-POLICY.md`.
3. Read your role: `agents/<slug>/ROLE.md`, then `agents/<slug>/HANDOFF.md`.
4. Read `work/STATUS.md`, then the claimed `work/<slug>/HANDOFF.md`.
5. For history only: `archive/chats/INDEX.md`, newest matching tag.

Then work from the files. Rewrite the handoff after every finished step.
