# Skills

Reusable, generic procedures for a Grok Bot fleet with Claude Code as the doer. Each folder has one `SKILL.md` with front matter (`name`, `description`) and plain steps. Copy the ones you need into your brain repo's `skills/` and edit the placeholders.

| Skill | Use when |
|---|---|
| [agent-brain-handoff](agent-brain-handoff/SKILL.md) | Start, checkpoint, and end of every session: sync bot state to the brain. |
| [session-compact-clear](session-compact-clear/SKILL.md) | A topic closed, a new task appeared, or context is getting thick. |
| [thin-desk-claude-code](thin-desk-claude-code/SKILL.md) | Deciding who does the work, and how to launch Claude Code on a ticket. |
| [retire-task-folder](retire-task-folder/SKILL.md) | A ticket is done: stop its session and archive its folder. |
| [email-send-self-test](email-send-self-test/SKILL.md) | Sending an email with a new format, links, or attachments. |
| [send-readiness](send-readiness/SKILL.md) | Checking whether an outbound campaign batch is safe to send. Report only. |
| [preview-first-outreach-email](preview-first-outreach-email/SKILL.md) | First-touch email to a business you already built a preview for. |
| [job-fit-eval](job-fit-eval/SKILL.md) | Scoring a job posting against a candidate profile. |
| [free-site-retainer](free-site-retainer/SKILL.md) | Drafting or positioning a free build plus monthly retainer offer. |
| [tasks-dashboard](tasks-dashboard/SKILL.md) | Rebuilding a simple task board page from an inbox log. |

Rules for every skill: no secrets, no real client data, no sending without an approval step, no em or en dashes in outbound copy.
